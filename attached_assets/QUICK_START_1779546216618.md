# ⚡ Replit에서 5분 안에 시작하기

## 체크리스트

### ✅ 준비 단계 (2분)
- [ ] Claude API 키 발급 받기
  - https://console.anthropic.com/account/keys
  - 새 API 키 생성 후 복사

- [ ] Replit 계정 생성 (없으면)
  - https://replit.com
  - GitHub나 이메일로 가입

### ✅ 배포 단계 (2분)

#### 방법 1: GitHub Import (가장 빠름)
```
1. Replit.com 방문
2. "Create" 버튼 → "Import from GitHub"
3. 이 폴더의 GitHub URL 입력
4. "Import" 클릭
```

#### 방법 2: 수동 생성
```
1. Replit.com → "Create" → "Node.js"
2. 터미널에 다음 입력:

cd ~
mkdir replit-project
cd replit-project

# server.js 생성
wget https://[당신의-url]/server.js

# package.json 생성
wget https://[당신의-url]/package.json

# public 폴더와 index.html 생성
mkdir public
wget https://[당신의-url]/public/index.html -O public/index.html

# 설치
npm install

# 실행
npm start
```

### ✅ 실행 단계 (1분)
- [ ] Replit "Run" 버튼 클릭
- [ ] 콘솔에 "🚀 서버 시작" 메시지 확인
- [ ] "Open in new tab" 클릭

### ✅ 첫 크롤링 (0분)
- [ ] Claude API 키 입력
- [ ] "🔄 업데이트" 버튼 클릭
- [ ] 완료 대기 (1-3분)

## 📝 API 크롤링 수동 요청

### cURL 예제
```bash
curl -X POST https://[프로젝트명].replit.dev/api/crawl \
  -H "Content-Type: application/json" \
  -d '{"apiKey":"sk-..."}'
```

### Python 예제
```python
import requests

response = requests.post(
    'https://[프로젝트명].replit.dev/api/crawl',
    json={'apiKey': 'sk-...'}
)
print(response.json())
```

### JavaScript 예제
```javascript
fetch('https://[프로젝트명].replit.dev/api/crawl', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ apiKey: 'sk-...' })
})
.then(r => r.json())
.then(data => console.log(data))
```

## 💡 팁

1. **팀 공유**
   - Replit URL을 이메일로 팀원들에게 공유
   - GitHub Repo를 Public으로 만들면 누구나 Fork 가능

2. **API 키 보안**
   - API 키를 GitHub에 올리지 말 것
   - Replit Secrets 사용 권장 (Advanced)

3. **데이터 백업**
   - `data/news.json` 정기적으로 다운로드
   - 또는 Google Drive에 자동 동기화

4. **로컬 테스트**
   ```bash
   npm install
   npm start
   # localhost:3000 에서 확인
   ```

## 📊 대시보드 사용법

### 상단 기능
- **API 키 입력**: Claude API 키 (비밀번호처럼 입력됨)
- **업데이트 버튼**: 즉시 뉴스 크롤링
- **검색창**: 키워드로 뉴스 검색

### 중앙 기능
- **카테고리 탭**: 업계뉴스 / 원재료동향 / 규제안전 / 해외뉴스
- **뉴스 카드**: 
  - 제목, 설명, AI 요약
  - 키워드 태그 (#농심, #대두)
  - 클릭시 원본 기사로 이동

### 하단
- **할당관세 정보**: 농림축산식품부 공지 링크
